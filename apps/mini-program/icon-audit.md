# 数字减重助手图标审计与整改记录

日期：2026-08-18

## 审计范围

- `pages.json` 注册的 20 个页面。
- 患者端、医生端、登录注册、医患绑定、消息、协议和测试页面。
- 公共 `Icon.vue`、8 个原生 tabBar PNG 图标及全部实际 SVG 引用。
- 检查维度：视觉尺寸、容器比例、颜色生效、语义准确性、触摸目标及资源路径。

## 修改前主要问题

- 117 个显式传色图标中有 76 个未命中 `Icon.vue` 的滤镜分支，页面传入蓝色、成功色、警告色或灰色时仍会显示为默认黑色。
- 返回、关闭、密码显隐、日期切换、周切换等独立操作的触摸目标多处不足 44×44px。
- 图标尺寸存在 12、14、16、18、20、22、24、26、32、40、48、64px 等零散档位，个别图标与底块比例拥挤或过小。
- 随访类型、科室、年龄、优先级等少量图标语义不准确；未选患者仍显示勾选状态。

## 已完成整改

- 公共图标颜色统一为主色、灰阶、成功、警告、错误、强调和反白七类语义色，并为每类提供真实 SVG 滤镜映射。
- 图标尺寸统一为：辅助信息 14px、表单/标题 16–18px、主要操作/卡片 20px、类型入口 24px、空状态 32–40px、成功反馈 48–64px。
- 所有实际 `Icon` 均显式声明尺寸和语义颜色；蓝色按钮内使用白色图标，选中/未选中状态直接切换图标颜色。
- 返回、关闭、密码显隐、日期/月/周切换和图片删除等独立图标操作统一为至少 88rpx（约 44px）触摸目标。
- 替换为真实语义 SVG：加餐、体重检查、饮食指导、运动计划、健康评估、用药复核、线下随访、科室、年龄和优先级。
- 修复未选患者也显示勾选图标的问题；无头像时使用中性用户图标，不再显示品牌 Logo。
- 原生 tabBar 图标与文字使用同一组选中/未选中颜色。

## 自动化契约

`scripts/check-icons.mjs` 现在检查：

- 每个实际 `Icon` 是否显式声明统一尺寸和语义色。
- 静态与动态分支中的 SVG 是否真实存在。
- 图标目录是否含会导致 H5 路径不稳定的空格或特殊符号。
- 是否出现尺寸档位外的临时数值或未映射颜色。

当前结果：182 个 `Icon` 实例、235 个静态/动态 SVG 引用全部通过。
